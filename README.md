# Accordion Component

A simple accordion UI built with HTML, CSS, and vanilla JavaScript. Each section can be expanded or collapsed by clicking its header, making it a lightweight interactive component for demos, landing pages, or forms.

## Features

- Expand/collapse accordion sections
- Pure HTML, CSS, and JavaScript implementation
- No frameworks or build tools required
- Responsive, clean card-style layout

## Project Structure

- `index.html` — page structure and accordion markup
- `styles.css` — accordion styling and layout
- `script.js` — interaction logic to toggle open/closed sections

## Getting Started

1. Open the project folder in a browser.
2. Open `index.html` directly, or serve the files locally:

```bash
cd /Users/kevingonzalez/Projects/accordionComponent
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Usage

Click any accordion header to reveal or hide the corresponding content. The current implementation toggles the `is-open` class to show the selected section.

## Notes

This project is intentionally minimal and beginner-friendly, making it a good starting point for learning how interactive components are built with the DOM and CSS state changes.
